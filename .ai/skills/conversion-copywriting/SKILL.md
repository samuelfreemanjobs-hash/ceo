# Conversion Copywriting

**Used by:** Funnel Architect (Phase 4 — Build)

## Formulas

| Formula | Structure | Best for |
|---------|-----------|----------|
| PAS | Problem → Agitate → Solve | Pain-aware audiences |
| BAB | Before → After → Bridge | Transformation offers |
| AIDA | Attention → Interest → Desire → Action | Broad awareness |
| 4Ps | Promise → Picture → Proof → Push | Direct response |
| FAB | Features → Advantages → Benefits | Technical products |

## Headline archetypes (8)

1. Specific outcome + timeframe
2. Audience call-out + promise
3. Contrarian / pattern interrupt
4. Social proof lead
5. Question that names the pain
6. Number + mechanism
7. Before/after contrast
8. Risk reversal lead

## Email sequence architectures

| Sequence | Emails | Purpose |
|----------|--------|---------|
| Welcome | 5 | Post-signup orientation |
| Nurture | 7 | Education → conversion |
| Sales | 4 | Offer push |
| Re-engagement | 3 | Win back inactive |
| Abandoned cart | 3 | Recover checkout |

## Landing page structure

Hero → Problem → Solution → Proof → Objection handling → CTA

## Evaluator-optimizer loop (high-stakes copy)

1. Generate **3 variants**
2. Critique each against:
   - Is the **audience** the hero?
   - Is there a **specific promise**?
   - Does it pre-empt the **top objection**?
   - Is the **CTA** crystal-clear?
3. Refine the strongest variant
4. Note claims requiring substantiation (route to compliance if external)
