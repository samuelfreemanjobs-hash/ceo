# Learnings (append-only)

Cross-cycle observations. Do not delete — add corrections as new entries.

## 2026-06-15 — GitAgent 6-layer stack

- Full stack per agent (ops, SOUL, SKILLS, SUBAGENTS, DUTIES, rules, memory) dramatically improves delegation consistency vs flat prompts alone.
- Tier-adaptive Cleo reduces unnecessary multi-agent cost; ~60% of requests should stay Tier 0–1.

## 2026-06-15 — Automation path to 80%

- Team-brain at repo root is prerequisite for cross-session automation (not just starter-kit copy).
- Pre-commit metadata injection + CI validation prevents silent prompt drift.
- Human gates must be explicit (`*approve`, Pepe Apply, outbound comms) — chat-only gates do not scale.
