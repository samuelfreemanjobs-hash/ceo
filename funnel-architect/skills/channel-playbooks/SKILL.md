# Channel Playbooks

**Used by:** Funnel Architect (Phase 3 — Map, Phase 4 — Build)

## Channel-fit matrix (summary)

| Channel | Fits when | Poor fit when |
|---------|-----------|---------------|
| Paid search | High intent, known category | Pre-category / education-heavy |
| Meta ads | B2C, visual offer, broad demo | Niche B2B with long cycle |
| LinkedIn ads | B2B, defined titles | Low ACV consumer |
| SEO / content | Long horizon, compounding | Need revenue in 30 days |
| Email | Owned list, lifecycle | No list, no capture |
| Outbound | High ACV, defined ICP | Low ACV, self-serve PLG |
| Partnerships | Complementary audiences | No partner motion yet |
| Community | Dev tools, prosumer | Commodity without identity |

## Per-channel playbook structure

For each channel assigned to a stage, document:

1. **Mechanics** — how the channel works for this stage
2. **Math** — typical CPL/CAC range (cite source or label heuristic)
3. **Creative patterns** — what converts
4. **KPIs** — primary + guardrail metrics
5. **Failure modes** — common mistakes

## Channel concentration principle

Pick **1–2 channels to dominate** before adding more. Flag sprawl in recommendations.

## Honest assessments

State when a channel is overhyped for the user's stage (e.g., podcast ads at $0 MRR).
