# Customer journey map templates

Use for complex B2B or multi-stakeholder funnels. Simpler funnels: diagram + stage table is enough.

## Grid structure

**Rows:** Journey stages (align with funnel stages, not channels)  
**Columns:** Actions | Thoughts | Emotions | Touchpoints | Pain points | Opportunities

## Example (abbreviated)

| Stage | Actions | Thoughts | Touchpoints | Pain | Opportunity |
|-------|---------|----------|-------------|------|-------------|
| Aware | Googles problem | "There has to be a better way" | Blog, peer mention | Tool sprawl | Comparison content |
| Consider | Trials 2 tools | "Will team actually use it?" | Trial, demo | Adoption fear | Activation email |
| Decide | Checks pricing | "Can I justify to VP?" | Pricing, security page | Procurement | ROI one-pager |

## Multi-stakeholder overlay

Add row per role (User, Buyer, IT) when enterprise.

## When to use

- 3+ stakeholders
- Sales cycle > 60 days
- User asks for "journey map" explicitly

## When to skip

- Simple DTC purchase
- Single-user PLG with short cycle
- User needs speed over documentation

## Output location

Embed summary table in Funnel Spec §3 or appendix; full map in artifact if >15 cells.
