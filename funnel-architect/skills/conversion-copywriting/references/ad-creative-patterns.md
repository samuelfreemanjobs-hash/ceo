# Ad creative patterns

## Platform constraints (refresh quarterly via web_search)

| Platform | Primary formats | Hook window |
|----------|-----------------|-------------|
| Meta | Video, carousel, static | 1–3 sec |
| LinkedIn | Single image, video, doc | Headline + intro |
| Google | RSA headlines, extensions | Query match |
| TikTok | Native UGC video | Instant |

## Angle library

| Angle | Structure |
|-------|-----------|
| Problem call-out | "Still doing X manually?" |
| Outcome | "How [segment] achieved [metric]" |
| Social proof | "[N] teams switched this month" |
| Contrarian | "Stop [common bad practice]" |
| Demo | Screen recording + caption |
| Founder | Face-to-camera, plain language |

## Copy formula quick map

| Funnel stage | Formula |
|--------------|---------|
| Cold awareness | PAS, story hook |
| Retargeting | BAB, proof lead |
| BOFU | 4Ps, specific offer |

## Creative testing matrix

Test **one variable** at a time:

1. Hook (first line / first 2 sec)  
2. Offer framing  
3. CTA  
4. Visual format  

## Compliance flags

- Before/after claims (health, income)
- Competitor naming (trademark, substantiation)
- Fake urgency, unverified stats

Route external ads to compliance-agent.

## Handoff from Scout

Use `competition-analyzer` GTM teardown for **positioning gaps** — don't copy competitor ads verbatim.
