# Positioning Frameworks

Positioning is a **choice about what game you're playing and who you're playing it for**. This skill forces that choice before any value prop or packaging work.

## When to run

- Start of every Offer Builder session (discovery + position phases)
- User says "we're like X but better" — reframe into differentiated position
- Scout handoff includes white-space — translate into positioning hypothesis

## Discovery minimum (do not skip)

| Field | Why |
|-------|-----|
| Product (what it does) | Can't position vapor |
| ICP segment (specific) | Positioning without segment = generic |
| Primary outcome | Position on job, not feature |
| Named alternatives | Users always compare — name them |
| Switching trigger | Positioning must answer "why now" |
| Constraint | Price tier, geography, compliance, motion |

If Scout artifact exists, extract: white-space hypothesis, crowded plays, competitor positioning summaries.

## Framework selection

| Situation | Framework | Output |
|-----------|-----------|--------|
| Crowded category, need wedge | **Wedge positioning** | Narrow ICP or use case until differentiation is obvious |
| New category creation | **Category design** | Name the category; educate market on why old category fails |
| Clear incumbent to contrast | **Contrast positioning** | Explicit "unlike X, we Y" with proof requirement |
| Multiple segments | **Primary + deferred** | One primary position; note secondary as separate spec |
| Post-Scout white space | **White-space → position** | Hypothesis → testable positioning statement |

## Positioning statement template

> For **[ICP]** who **[job/trigger]**, **[product]** is the **[category]** that **[key differentiation]** unlike **[primary alternative]**.

**Rules:**
- ICP must be narrow enough to exclude someone
- Category must be recognizable OR deliberately new (with education plan)
- Differentiation must be **provable** or flagged Unverified
- Alternative must be named (competitor, status quo, or DIY)

## For / against frame (required)

| For (ideal customer) | Not for |
|----------------------|---------|
| Specific firmographic + psychographic | Who will churn or never buy |
| Trigger they recognize | Who should use alternative |
| Budget / sophistication fit | Segments you're deferring |

## Evaluator loop (positioning statement)

On high-stakes positioning (new launch, reposition, category shift):

1. Generate **3 variants** — wedge, contrast, category-creation angles
2. Critique each: specificity, defensibility, proof availability, market literacy
3. Refine strongest; document why others were rejected

## Anti-patterns

- **"For businesses of all sizes"** — not a position
- **Feature differentiation only** — "we have AI" is not positioning
- **No named alternative** — positioning in a vacuum
- **Copying competitor position** — same category + same ICP = no wedge
- **Positioning without exclusion** — if everyone is a fit, no one is

## Handoffs

- **From competition-analyzer:** white-space, crowded plays, competitor positioning
- **To value-proposition-design:** approved positioning frame + proof gaps
- **To funnel-architect:** ICP + category label for funnel framing
