# BANT + fit checklist

## Budget
- [ ] `opportunity.amount_estimate` from CRM or `unknown`
- [ ] Rep-stated budget in rep_brief cross-checked
- [ ] Dispute recorded if mismatch

## Authority
- [ ] `decision_makers[]` with role tags
- [ ] Economic buyer named or gap flagged
- [ ] Champion vs blocker signals from transcripts

## Need
- [ ] Each `pains[]` has `evidence` (verbatim)
- [ ] Pains trace to activity or transcript source

## Timeline
- [ ] `expected_close` from CRM
- [ ] `urgency_signals[]` populated or gap noted

## Technical fit
- [ ] Integrations / stack from transcript or rep_brief
- [ ] Conflicts with catalog flagged for Solution Architect

## Political map
- [ ] Prior touchpoints summarized
- [ ] Competitors with context, not just names
